# FizzBuzz

## ルール

1 から順に数を数える。ただし以下の条件に従って置き換える。

- 3 の倍数 → `Fizz`
- 5 の倍数 → `Buzz`
- 3 と 5 両方の倍数（15 の倍数）→ `FizzBuzz`
- それ以外 → 数をそのまま文字列で返す

## 例

| 入力 | 出力 |
|------|------|
| 1 | `"1"` |
| 2 | `"2"` |
| 3 | `"Fizz"` |
| 5 | `"Buzz"` |
| 6 | `"Fizz"` |
| 10 | `"Buzz"` |
| 15 | `"FizzBuzz"` |
| 30 | `"FizzBuzz"` |
